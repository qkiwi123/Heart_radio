# AI接手入口：公开源码状态

本页说明公开快照的实现与限制，不包含任何个人设备的实时状态或原始验收材料。当前源码版本：电脑1.12.0-dashboard；手表1.11.2-retention/code45；MCP0.7.0/11工具。设备是否已安装、服务是否启动、开关是否允许，须在使用者自己的环境核对。

先按[SETUP](SETUP.md)完成构建与配对，再读[日常使用](DAILY-USE.md)；涉及Agent时，以[工具定义](../agent/tools.json)和[MCP契约](MCP-CONTRACT.md)为准。源码目录：app/手表，dashboard/电脑与网页，receiver/传输，agent/MCP，scripts/维护，desktop-widget/桌面小窗。
