# 日常使用

完成[构建和配对](SETUP.md)后，双击根目录Start-HeartRadio.cmd或已配置的桌面01。02只打开网页；03停止本项目电脑服务；04只暂停电脑心率接收；05～08分别开始、查看、结束和重算本地资源观察。关闭网页不停止后台，也不停止手表。

手表“连接、心率广播、Agent交互”分开控制。连接本身不采集心率；需要新设备读取、临时测量、用户状态或提醒时，由本人开启Agent交互并等待两端确认。连续心率由独立广播开关控制。电脑可只暂停接收，手表仍可能采集；关闭广播才同步结束采集。不同系统模式、无接触或超时可使结果不可用，不把空值写成0。

## 功能导航

仪表盘宽屏为左侧导航、窄屏为顶部导航。每次只显示一个独立页面，切换保留未提交输入、历史筛选及展开状态，不自动保存设置或启动测量：总览与连接、设备读取、发送提醒、心率趋势、心率历史、提醒历史、设置与小窗。页面地址支持刷新和浏览器前进/后退。

设备读取可连续点击不同指标，分别看结果与取消；同指标同窗口可共用在途测量。取消全部只捕获点击时的请求，必须等原请求确认监听/锁释放。新读标记不能绕过用户指标许可或请求间隔。心率历史按北京时间年月日/轮次分类，CSV导出仅包含项目记录，不是原生健康全量数据。

## 提醒与历史

立即提醒支持文字、振动、亮屏及默认关闭的系统通知音。总许可与单条设置同时满足才执行，受静音/勿扰/锁屏、通知和系统状态限制。最多300秒有效期，无未来排程。状态不确定时查询原编号，不换新编号自动重发。

提醒历史查看电脑当前保留的全部条目，每页20条，可搜索标题/正文/编号、按状态筛选并展开内容和时间。两端各最多128条，满额后新提醒替换已过期条目；全部未过期则拒绝新增。过期不等于立即删除正文，删除手表正文也不立即释放去重名额。

手表删除清除本机正文、通知和效果，保留最少去重字段；电脑继续保留原文并显示“手表已删除”。新路由或交互确认后，电脑在现有门禁内分批补查回执：每批最多4条，失败最多3次、重试至少间隔15秒，完成后不持续查询手表。只查状态，不重放效果；手表已淘汰编号时只能记录not_found，不能推断此前是否删除/执行。进入历史页面和刷新历史只读电脑；显式单条核对才查询设备。

## 期限、停止与数据

接收期限、交互期限及连续10分钟无业务连接的自动暂停分别生效。明确保存可改变期限，普通启动/重连不会续期。暂停后由本人用01和手表“开启连接”恢复；重启或不确定状态按原保护逻辑关闭相关业务，不自动复活提醒。不要靠启动MCP开启采集。

runs/存运行数据、历史、设置、缓存和提醒账本，.local-wifi/存本机配对。它们属于使用者自己的数据，不随公开源码上传。电脑诊断10MiB分段、14天/200MiB目标，关闭控制台7天/50MiB；手表2MiB分段、7天/32MiB。活动文件、迁移保护或.keep-logs标记可暂超目标。心率原始pc.jsonl、提醒账本、设置、配对和手动证据不进入诊断清理。CLI `scripts/cleanup_logs.py` 默认只预览，显式--apply才执行；不删除整个runs目录。
