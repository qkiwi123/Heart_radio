# 日常使用

首次完成构建和配对后，使用01～08桌面入口及 `http://127.0.0.1:8766/` 仪表盘。

| 入口 | 行为 |
| --- | --- |
| 01 启动桌面心跳 | 启动电脑心率接收及仪表盘，按保存的设置准备电脑按需服务。重复启动不会重复开服务。 |
| 02 仅打开仪表盘 | 查看状态和已保存历史，不自动开启接收或手表采集。 |
| 03 停止电脑端 | 停止本项目电脑服务和小窗，尝试结束在线手表待命；不会退出用户的 Agent。 |
| 04 仅停止接收 | 只停止电脑心率接收，保留仪表盘、按需服务及小窗。 |
| 05 开始资源测试 | 启动默认60分钟的资源记录，实际数据保存本机。 |
| 06 查看资源测试进度 | 查看记录状态和进度。 |
| 07 提前结束资源测试 | 结束资源记录，不直接停止正常采集。 |
| 08 重新生成资源报告 | 根据已保存记录生成报告，不补造缺失时段。 |

手表左侧“开启/关闭心率广播”和右侧“开启/关闭待命通道”独立控制。初次打开两项关闭；按钮文字与颜色反映运行状态。心率广播负责原实时心率及相关通道状态，待命负责接收请求；开启待命不会连续上传所有传感器数据。返回表盘、自然熄屏后，已开启服务按各自期限运行。

仪表盘心率接收与按需服务各自支持不限时和自定义时长，保存立即生效。手表待命默认30分钟，也支持独立不限时和自定义设置。选择并保存“跟随电脑设置”后，电脑保存待命时长会同步给在线手表；离线或尚未同步时以手表显示的实际状态为准。重复启动入口和自动重连不重新延长既有期限。

按需数据设置控制指标、默认测量窗口、缓存及请求间隔。网页和 MCP 共用同一限制；要求新测量不能绕过间隔或同时启动多个采集。测量结束后检查成功状态、单位、缓存年龄及监听释放结果。取消请求后，应等待原测量结束并确认清理，不能把取消命令被接收视为清理完成。

心率查询使用原广播缓存，不另外注册心率监听。无接触、离线、停止或数据过期时不显示伪造数值。接收年龄表示电脑收到数据至今的时间，源传感器时间戳的年龄没有独立校准。停止服务后历史仍保存在本机，02可继续查看。

已开启的两条通道可以在网络恢复后发现同一已配对电脑并重连。网络隔离、不同热点或跨互联网连接不在此保证范围。主动关闭服务或期限到达后，需要本人再次开启；启动 MCP 不会替用户开启手表。

运行记录位于项目的 `runs/`、`evidence/` 等本机目录，配对在 `.local-wifi/`。这些数据被公开版本忽略，不应另行上传。
