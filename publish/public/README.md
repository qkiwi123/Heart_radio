# HeartRadio：基于MCP的穿戴设备接入电脑agent

HeartRadio 将 OPPO Watch 2 接入 Windows 电脑，让手表采集的心率和支持的健康数据可以在本机保存，也让电脑上的 Agent 能通过 MCP 与手表交互。

- **健康数据传输与本地保存**：手表通过蓝牙或局域网 Wi-Fi 向电脑传输心率；开启健康归档后，还可保存原厂步数、佩戴观测、睡眠分期、原厂心率及成功的压力点测。仪表盘支持查看实时心率，在单日时间轴联看心率、睡眠、步数和压力记录，并按日期查询历史、将 HeartRadio 采集的心率导出为 CSV。
- **通过 MCP 读取手表数据**：电脑上的 Agent 可以读取电量等设备状态，按需获取心率、气压、加速度和陀螺仪数据，也可以确认手表是否在腕、读取累计步数、最近的原厂睡眠报告，或按需组合读取用户状态和原厂压力点测。获得历史读取许可后，还可在手表离线时查询电脑已归档的健康数据。
- **通过 MCP 向手表发送提醒**：Agent 可以立即发送文字提醒，按用户设置搭配振动、亮屏或提示音，并查询提醒回执与用户确认状态。

从手表获取新数据或发送提醒前，需要连接手表、开启 Agent 交互，并等待两端同步。健康自动归档与 Agent 历史读取授权默认关闭，可在仪表盘分别设置；查询已有电脑归档不需要手表在线。

目前适配 OPPO Watch 2（OW20W2 / Android API27）。当前源码为电脑 **1.18.0-stress-history**、手表 **1.14.1-stress / code56**、MCP **0.13.0 / 13 项工具**。设备安装和配置步骤见使用说明。

**AI 接手先读[源码状态与边界](docs/PROJECT-STATUS.md)，操作看[日常使用](docs/DAILY-USE.md)，工具调用看[MCP契约](docs/MCP-CONTRACT.md)。**

| 功能 | 行为与边界 |
| --- | --- |
| 连接与开关 | 已配对蓝牙 RFCOMM 或本地 Wi-Fi/TLS，支持自动优先或固定选路。连接、连续心率和 Agent 交互独立控制；新设备动作需要两端确认的交互许可。 |
| 按需数据 | 设备状态、最多15秒的一次性心率、1～10秒气压/加速度/陀螺仪；不同指标可并发，同指标同窗口共用。可能超时、无接触或无有效数据。 |
| 立即提醒 | 文字、振动、亮屏及默认关闭的系统提示音，服从用户限额与系统限制。只有明确点击确认才算已确认；无未来排程或断线自动补发。 |
| 独立功能页面 | 总览与连接、设备读取、发送提醒、实时心率记录、手表健康历史、提醒历史、设置与小窗。切换保留未提交输入，不触发新采集。 |
| 提醒历史 | 电脑保留内容搜索、状态筛选、分页与回执核对。两端各128条，满额替换已过期记录；手表删除不清除电脑原文。重连分批补查状态，不重放效果。 |
| 用户状态与原厂健康 | 可单次查询累计步数、佩戴与当前睡眠。综合状态先查佩戴，再按需选查睡眠、心率、加速度和陀螺仪；两路运动支持未经独立验证的活动分档。原厂睡眠事件可能晚于实际变化。 |
| 原厂压力点测（实验） | 显式选择压力、确认在腕并启用手表压力无障碍服务后，亮屏打开原厂测量页。仅返回本次有效分数，失败或超时不复用旧值；成功且已开启归档时保存。原厂完整压力历史尚未接通。 |
| 手表健康历史 | 开启归档后保存受支持的原厂活动、佩戴、睡眠和心率记录，以及本项目成功触发的压力点测。单日时间轴可联看心率、睡眠分期、步数和压力记录，区分缺记录与零值；历史读取仅访问电脑库。 |
| 日志管理 | 电脑诊断14天/200MiB、关闭控制台7天/50MiB；手表诊断7天/32MiB目标。保护活动文件与保留标记；心率原始历史、提醒、设置、配对不进入诊断清理。 |

本仓库公开源码、通用说明与人工生成的测试数据，不包含个人运行数据、配对凭据或设备日志。原厂健康接口目前针对 OPPO Watch 2（OW20W2 / A.92 固件）适配，指标可能缺失、延迟或不可用，不用于医疗判断。实时与历史边界见 [MCP 契约](docs/MCP-CONTRACT.md)。

在 Windows 完成[环境准备](docs/SETUP.md)后，运行根目录的 [Start-HeartRadio.cmd](Start-HeartRadio.cmd) 即可打开本地仪表盘（`http://127.0.0.1:8766`）。仓库也提供 [桌面入口 01～08](launchers/desktop)。

蓝牙不要求两端同一Wi-Fi；选择Wi-Fi时需要可互通的局域网与本地TLS配对。Agent不自动开启连接或业务；云端模型仍可能接收工具返回的数据。本项目没有承诺跨设备通用、全天稳定、开机自启或强制停止后远程唤醒。
