# HeartRadio：手表心率与本地 Agent 数据接口

HeartRadio 由 Android 手表应用、Windows 接收服务、网页仪表盘和独立 MCP 接入包组成。心率通过 Wi-Fi 持续发送；设备状态、气压、加速度和陀螺仪通过待命通道按需读取。电脑服务和手表服务分别由用户开启，Agent 查询不会自动启动采集。

当前手表应用版本为 `1.3.8-probe`。项目针对 OPPO OW20W2、Android API 27 开发，安装与诊断脚本会核对设备身份。其他型号需要适配和实际验证，不能根据传感器名称保证所有数据可读。本仓库公开源码、人工生成的测试数据和通用说明；个人实测记录、设备日志、配对凭据及原始开发历史不在公开版本中。

| 功能 | 使用方式 |
| --- | --- |
| 心率广播 | 手表左侧开关；电脑持续接收，仪表盘查看当前值和本地历史。无接触、停止或过期时显示实际状态。 |
| 按需数据 | 手表右侧待命开关；网页或 Agent 请求短时采集，结束后释放监听与短时唤醒。 |
| 时长与节电 | 心率和待命独立控制；待命支持默认30分钟、不限时、自定义及可选跟随电脑设置。 |
| 桌面入口 | 沿用01～08启动、查看、停止和资源记录入口，支持桌面小窗。 |
| Agent 接入 | 导出独立 stdio MCP 目录，由用户手动启动 Agent，阅读目录 README 后自行配置。 |

两条手表链路均使用局域网 Wi-Fi 和本地 TLS 配对。仪表盘及工具接口绑定电脑的 `127.0.0.1`。网络恢复后，已开启的服务可重新发现同一已配对电脑；明确关闭的服务需要本人重新开启。电脑与手表必须处于可互通的同一局域网。

GPS 目前保留诊断入口，默认 MCP 工具不提供位置坐标。计步、血氧、心电和厂商原始通道也未列入默认工具。原始运动数据不用于推断活动类型或医疗结论。

源码目录：`app/` 为手表端；`receiver/`、`dashboard/`、`desktop-widget/` 为电脑端；`agent/` 为 MCP；`scripts/` 为启动、诊断和发布工具；`launchers/desktop/` 为01～08快捷入口。运行数据保存在本机的忽略目录中，仓库不附带个人数据或已经配好的连接信息。
