# HeartRadio：手表、电脑与 Agent 的本地协作

面向 OPPO Watch 2（OW20W2 / Android API27）的个人项目：连续心率、按需读取、立即提醒、Windows 仪表盘与桌面小窗，以及独立 stdio MCP。当前源码为电脑 **1.12.0-dashboard**、手表 **1.11.2-retention / code45**、MCP **0.7.0 / 11项工具**。克隆源码不表示你的设备已安装或环境已配置。

**AI 接手先读[源码状态与边界](docs/PROJECT-STATUS.md)，操作看[日常使用](docs/DAILY-USE.md)，工具调用看[MCP契约](docs/MCP-CONTRACT.md)。**

| 功能 | 行为与边界 |
| --- | --- |
| 连接与开关 | 已配对蓝牙 RFCOMM 或本地 Wi-Fi/TLS，支持自动优先或固定选路。连接、连续心率和 Agent 交互独立控制；新设备动作需要两端确认的交互许可。 |
| 按需数据 | 设备状态、最多15秒的一次性心率、1～10秒气压/加速度/陀螺仪；不同指标可并发，同指标同窗口共用。可能超时、无接触或无有效数据。 |
| 立即提醒 | 文字、振动、亮屏及默认关闭的系统提示音，服从用户限额与系统限制。只有明确点击确认才算已确认；无未来排程或断线自动补发。 |
| 独立功能页面 | 总览与连接、设备读取、发送提醒、心率趋势、心率历史、提醒历史、设置与小窗。切换保留未提交输入，不触发新采集。 |
| 提醒历史 | 电脑保留内容搜索、状态筛选、分页与回执核对。两端各128条，满额替换已过期记录；手表删除不清除电脑原文。重连分批补查状态，不重放效果。 |
| 用户状态 | 新采集一次完整30秒运动观察，返回三档弱推测或未知。不是自动佩戴、睡眠或走路检测，未经准确率测定。 |
| 日志管理 | 电脑诊断14天/200MiB、关闭控制台7天/50MiB；手表诊断7天/32MiB目标。保护活动文件与保留标记；心率原始历史、提醒、设置、配对不进入诊断清理。 |

本仓库只公开源码、通用说明与人工生成的测试数据。没有个人心率采样、提醒原文、设备日志、配对凭据、私钥、APK或原始本地开发历史。运动、状态和提醒均有明确的可用范围，不用于医疗判断。原生睡眠、血氧、心电、计步、佩戴检测和有效新定位不在默认工具范围内。
